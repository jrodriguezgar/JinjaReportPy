# Security Policy

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do NOT open public issues for security vulnerabilities.**

Instead, report vulnerabilities via [GitHub Security Advisories](https://github.com/jrodriguezgar/JinjaReportPy/security/advisories/new).

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Acknowledgment**: Within 5 business days
- **Assessment**: Within 10 business days
- **Fix**: Depending on severity, typically within 30 days

### Process

1. Submit a vulnerability report via GitHub Security Advisories
2. We will acknowledge receipt and begin assessment
3. We will work on a fix and coordinate disclosure
4. A security advisory will be published with the fix release
